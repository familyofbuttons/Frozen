Host on GitHub Pages (100% Free!)

Access your inventory on phone, tablet, or PC anytime!

1
Create a GitHub Account & Repository

Go to github.com, sign up or log in, and click "New Repository". Name it freezer-inventory.

2
Upload File

Click "uploading an existing file" and upload this file as index.html.

3
Enable Pages

Go to **Settings** → **Pages**. Under **Build and deployment / Branch**, select main branch and click **Save**.

4
Access Anywhere

In 1-2 minutes, GitHub gives you a link (e.g., https://yourusername.github.io/freezer-inventory). Bookmark it or save it to your phone screen!
